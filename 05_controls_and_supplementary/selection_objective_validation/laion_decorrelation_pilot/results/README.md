# Results

Generated CSV outputs for the LAION decorrelation pilot.

- `selection_indices.csv`: selected image indices for each selection objective.
- `noise_curves.csv`: noisy in-silico model-recovery curve values.
- `summary_auc.csv`: AUC and empirical-noise summaries.
- `noise_calibration.csv`: calibrated RDM-space noise variances.
- `run_metadata.json`: command/config metadata.
