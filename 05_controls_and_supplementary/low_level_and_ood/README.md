# Low-Level And OOD Controls

This subgroup checks whether the controversial-stimulus effect can be explained
by image statistics or by the selected images being out of distribution for the
model/image pool. It is split into:

- `image_statistics/`: low-level image-feature summaries and diagnostics.
- `ood_controls/`: out-of-domain scoring, controls, and matched comparisons.

Use these analyses before interpreting a brain-model alignment change as a
model-disagreement effect rather than a simpler image-property or distribution
shift effect.
