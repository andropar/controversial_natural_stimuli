# Model-Scope Follow-Ups

This subgroup asks whether the main alignment conclusions depend on which model
layers, ROIs, model families, or discriminability definitions are used. It is
where broad model-scope checks live rather than the primary score production in
`01_brain_model_alignment/`.

- `layer_sweep/`: layer-wise alignment sweeps and best-layer summaries.
- `roi_analysis/`: ROI-specific alignment follow-ups.
- `discriminability/`: checks on model separability/discriminability.
