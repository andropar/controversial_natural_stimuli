# Stimulus Characterization

`01_characterize_stimuli.py` summarizes the available image-level statistics for
controversial, same-session baseline, and training pools. It uses the existing
low-level statistics table from `08_image_statistics`. OCR/object/scene labels
are recorded as unavailable unless local annotations are added.
