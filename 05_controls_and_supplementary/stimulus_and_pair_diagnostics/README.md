# Stimulus And Pair Diagnostics

This subgroup describes the selected images and selected image pairs directly.
Use it to inspect what kinds of images were selected, how image pairs sit in
brain or feature space, and whether the stimulus set has obvious content or
pair-level structure that should qualify the interpretation of the alignment
effect.

- `stimulus_characterization/`: image-level summaries and visual/content
  diagnostics.
- `pair_level_brain_placement/`: pair-level placement in brain-derived
  representational geometry.
